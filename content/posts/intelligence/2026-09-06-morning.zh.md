## 早报重点

### Astra 已开放到哪些套餐？区分 Chat 与 Work/Codex

OpenAI 9 月 4 日（UTC）更新：Astra 已向 Work/Codex 的 Pro、Enterprise、Business Premium 开放，API 也已上线；Plus、Business 仍需数日。另帖称 Chat 中由 Astra 驱动的 GPT-6 Pro 已向 Pro、Business、Enterprise 开放。

这不是重复首次发布，而是后续实际开放范围：Chat 的 GPT-6 Pro 与 Work/Codex 的 Astra 分批开放口径不同，不能把套餐列表混用。

**读者价值：** 先确认使用入口和套餐，再判断为何自己的账号还看不到模型。

**可以做什么：** 分别检查 Chat 与 Work/Codex 的模型选择器；API 用户按 API 可用性测试，不用 Chat 套餐范围推断权限。

### Simon 实测：先试低推理档，再比较单次成本

Simon Willison 用同一“鹈鹕骑自行车”SVG 任务比较推理档位：他认为 Astra low 的结果已优于所测 Sol 各档，单次花费 9.55 美分。Astra 单价较高但输出 Token 更少；这是单个示例，不能视为通用排名。

相较厂商发布，这是带推理档位与实际成本的个人对照实验；作者同时指出，低于 max 的结果仍会出现腿部位置错误。

**读者价值：** 选档位应比较达标结果的总成本，而不是只看每百万 Token 价格或默认选择最高档。

**可以做什么：** 用自己的一个固定任务测试 low、medium、max，记录是否达标、总 Token 和实际费用，再选默认档位。

### 让代理真能调试：固定场景、状态接口、真实交互

OpenAI 的游戏开发复盘给出可迁移的调试方法：给代理固定测试场景、可读取状态及性能计数器，用 Playwright 复现问题、检查截图和状态、修改后重跑；作者仍亲自判断操作手感。

固定场景用于复现，独立旅程测试通过真实控制验证降落、上下船和起飞，不把直接设置完成状态误当作流程通过。

**读者价值：** 界面能截图不等于流程可用；状态观测和真实交互测试能减少假验收。

**可以做什么：** 为一个关键交互加入固定起点、状态断言和真实操作回归测试，不只检查最终截图。
