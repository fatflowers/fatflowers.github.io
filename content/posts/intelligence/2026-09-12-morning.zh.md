## 早报重点

### OpenAI 将 Agents API 以公测形式开放

OpenAI 于 2026 年 9 月 10 日宣布 Agents API 进入公测，把 Codex 使用的托管代理运行框架通过 API 提供给开发者。调用可指定模型、工具、环境和并发子代理，并可选择 OpenAI 托管或自托管计算环境。

新增处于公测阶段的 Agents API：开发者可创建带工具、环境与多代理并发配置的云端代理会话；这不同于此前只面向 Codex 或 ChatGPT Work 的托管代理能力。

**读者价值：** 需要长期运行、可调用工具的代理应用，可评估是否用托管运行框架替代自行维护上下文、工具协调和执行环境。

**可以做什么：** 对照 Agents API 文档，在现有工具调用任务上测试托管与自托管环境的权限、时延和成本差异

### OpenRouter Fusion 加入多模型审议推理

OpenRouter 发布 Fusion：调用模型可按需把问题交给 1 至 8 个模型并行回答，由 judge 比较分歧后生成最终答复。默认三模型面板约为单次完成的 4 至 5 倍成本、2 至 3 倍时延，适合高代价的研究和评审任务，不适合实时或要求可重复输出的流程。

新增 openrouter/fusion 模型别名和 server tool 路径，将多模型面板、judge 与合成步骤封装为一次推理能力；官方给出成本、时延和适用边界。

**读者价值：** 团队可把多模型复核作为选择性升级路径，而非自行编排面板和裁判；也需预先接受更高成本、时延和非确定性。

**可以做什么：** 选取一个高错误代价的真实研究任务，对照当前单模型方案记录接受结果率、总成本和端到端时延。
